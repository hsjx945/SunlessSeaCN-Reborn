## 经验候选

1. Unity 6 数据根迁移会造成“UI 已中文、剧情仍英文”；必须用实际 `Application.persistentDataPath` 和运行时内容探针确认。
2. macOS sealed bundle 的临时补丁文件必须位于 bundle 外事务目录；失败回滚后必须严格验签。
3. manifest 卸载必须先全量只读预检，任一缺失/修改都要零写入退出。
4. Bash 3.2 + `set -u` 下不能在同一 `local` 声明中读取同一声明内刚赋值的变量。
