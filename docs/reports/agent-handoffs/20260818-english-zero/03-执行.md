## 实现与证据

- overlay 应用到隔离 build 后输出 `applied=229`，scanner 输出 `visible-english-findings=0`；源 payload 首次审计为 245 条，翻译后零条。
- patch report 明确记录：`target-intro=...IntroScript::PlayEAWarning()`、`bootstrap-intro-action=injected`、`target-title=...TitleScreenInit::Start()`、`bootstrap-title-action=injected`；重复运行由静态测试验证两者均保持 exactly one call / `already-injected`。
- overlay 每项包含 `id`、`field`、`source`、`translation`、`context`；应用器拒绝重复键、源值漂移、非唯一命中和空字段。
- scanner 检查非归档顶层 Event、未归档 ChildBranch 与其 Default/Success/RareDefault/RareSuccess result 的 `Name`、`Description`、`Teaser`、`ButtonText`，清理 HTML 标签、格式占位符、URL、技术 token 和单字母标记；支持直接扫描源 JSON 和 ZIP 的最终 payload，未遍历 Deck、LinkToEvent 或资源元数据。
- AlertDialog 已覆盖 Warning、分辨率提示、Fatal Error、存档恢复/双损坏、服务器错误（含 `There was a problem connecting to the server`）、导入失败、存档失败等；VideoOptionsPanel 另有分辨率方法级 transpiler；AdvertBlock.WarnAndVisitURL 精确替换外链标题和正文。
- TitleScreen Postfix 保留版本号数字，显示 `无光之海：潜海者 版本 <数字>`；SupportLink 仅改标签、不改原有点击 URL；Copyright 改为中文归属文本。两个 TitlePanel child 均加载已有 `Title.png`，源码没有 `GetImageTexture2D("TitleZMNew.png")` 调用。
