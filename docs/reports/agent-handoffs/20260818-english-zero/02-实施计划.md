## 设计

1. 新增 `localization/macos/events-name-overrides.json`：每项包含 `id`、`field`、`source`、`translation`、`context`。只对英文原文独立翻译，不直接复制 CC BY-NC-SA 繁中译文。
2. 新增 `scripts/apply-macos-localization-overrides.py`：递归索引 JSON 对象 ID；每个 overlay 必须唯一命中且旧值等于 `source`；不满足立即非零退出；序列化结果保持 UTF-8 且可重复。
3. `scripts/build-macos-static-ui.sh` 在复制 vendor addon 后立即应用 overlay，不直接修改 `build/`、`dist/` 或 vendor ZIP。
4. 新增 `scripts/audit-macos-visible-english.py`：检查非归档的顶层 Event、ChildBranch 和其 Default/Success/Rare result 的玩家可见 `Name`；明确跳过 Deck、Notes、资源名、枚举和技术指令。如有确实不可见值，使用带 ID/原值/理由的窄 allowlist，禁止宽泛正则豁免。
5. `SS_AlertDialog.cs` 增加构造函数 Prefix，集中处理 `Warning`、分辨率正文、`Fatal Error`、存档损坏标题/正文与服务器错误；保留 Continue 按钮 Postfix。动态文本仅对精确已知前缀/后缀拼接，不作任意机器翻译。
6. `SS_LatestNews.cs`、`SS_CharacterRepository.cs`、`SS_MenuProvider.cs` 补齐已知低频路由；避免与通用 AlertDialog 重复修改同一字符串。
7. 测试：
   - overlay 正常应用、旧值不符拒绝、重复 ID 拒绝；
   - scanner 对故意注入的可见英文失败，对内部资源名通过；
   - 反编译/静态检查 translation DLL 确认已知弹窗原文和中文对应关系存在；
   - `test_macos_static_ui.sh`、`test_macos_package.sh` 与新漏翻测试全部通过；
   - 扫描最终 ZIP payload，而非只扫描中间产物。
8. 实机：安装新包，触发 >1920×1080 分辨率警告；检查新游戏初始剧情、地图、设置与一个低频弹窗。不能安全触发的损坏存档路由由精确 IL/单元测证据代替，不破坏用户真实存档。

## 文件所有权

`luna_deep` 可修改：`localization/macos/**`、上述 4 个 C# 补丁文件、`scripts/apply-*`、`scripts/audit-*`、`scripts/build-macos-static-ui.sh`、`tests/test_macos_visible_english.sh`、与现有两个 macOS 测试的最小接线。不得修改 Windows 文件或执行 release/tag。

## 路由选择

选择 `luna_deep xhigh`：这是架构已定的多文件局部实现，主要难点是 JSON 定位、译文完整性与回归门禁，不涉及并发、迁移或复杂状态一致性，不需要 `luna_worker max`。

## 经验候选

延续 01 的“生成产物不是翻译真源”候选；待 overlay 和最终 payload 回归真实通过后再评估沉淀。
